# 《余烬》玩法 / 生命周期 / 社区合规审计

对照放置热门循环（产出 → 吞吐 → 仓容；稀疏高价值掉落；回访钩子=满仓/可收/可升级），对本机三键闭环做最严格核对后的结论与整改。

## 审计结论（整改前）

| 编号 | 问题 | 人类/放置逻辑 | 处置 |
| --- | --- | --- | --- |
| A1 | 菜地埋在「管理」第 6 项 | 生产应是一等公民（Egg Inc / Melvor 技能栏） | 据点首页首项进独立菜地页 |
| A2 | 仓库容量绑死食堂等级 | Idle Miner：仓库是独立瓶颈 | `stash_lv` 1–3 零件扩容 |
| A3 | 谷种只靠铁棚 | 缺种即断生产；远征应有稀有补给 | 远征成功低概率掉种 |
| A4 | 余烬几乎只出深处 | 稀有货币应全图低概率见光 | 非深处成功极低概率 +1 |
| A5 | 管理 12 项过深 | 三键会话必要决策应稀疏 | 据点枢纽 9 项；建设子页 |
| A6 | 仓满无明确召回 | 放置回访钩子=满仓 | 电台「仓满 · 先扩仓库」 |
| A7 | 菜地可收无主页提示 | 上线应一眼看到可收 | 主卡副文/据点首项提示 |

## 生命周期（整改后）

新档 → 近路 → 建设 → 开闸/深处 → 铁棚/菜地/猎场/灰潮。中期：满仓→扩容/货架；无种→远征或交易；线索二→渡口+薯。软锁守卫不变；数值全有盖。

## 社区合规

- 文案只谈门后、营地、种地、仓库、交易、猎场；不写芯片/框架。  
- 数值无爆炸、无强制付费、无清档惩罚螺旋；无内购/广告/抽卡/第二套时钟。  
- 简介可写「测试终点是起点」；配图不冒充实机截屏。  
- 发布凭据只在本机 `~/.config/folotoy/`，不进仓库。

## H 轮：内存与电源（ESP32-C3 · 无 PSRAM）

对照 `FoloToy-AI-Passport.map`（站事固件 `11e5a631…`）与运行路径做严格核对。**J 轮代码复核：** 路径仍在；Flash 另嵌约 242 KiB 电台 PCM（rodata）。

### 内存快照（链接期）

| 项 | 数值 | 判定 |
| --- | --- | --- |
| IRAM `.iram0.text` | ≈68 KiB | 可接受 |
| DRAM 静态（含 LVGL 48 KiB 池） | ≈130 KiB / 段长 ≈319 KiB | 堆余量约 180 KiB 量级 |
| LVGL 池 `CONFIG_LV_MEM_SIZE_KILOBYTES` | 48 KiB | 主屏对象多，已抬高；启动打 `lv_mem_monitor` |
| DMA 画缓冲 | 240×40×2 ≈19.2 KiB 单缓冲 | 符合无 PSRAM 预算 |
| `s_game` BSS | 568 B | 小 |
| 场景精灵 | Flash rodata；`.bss`/`.data`=0 | **通过**（不进内部 RAM） |
| 字库子集 | Flash ≈75 KiB 级 | 通过 |
| 电台 PCM（5 段） | Flash ≈242 KiB | 通过（8 MB factory） |
| 蓝牙 | `CONFIG_BT_ENABLED=n` | 通过 |
| Wi-Fi 栈 | Kconfig 默认仍链 `libesp_wifi`，应用从不 init | **残留**：射频冷；切断链接需更深组件裁剪，本轮不做 |
