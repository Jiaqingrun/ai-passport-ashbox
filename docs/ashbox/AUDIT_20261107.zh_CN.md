## 1. Flash / 固件体积

### 镜像身份

| 项 | 值 |
| --- | --- |
| 归档 | `build/firmware/9b6580f286741890af1eea1e9071c0f512a7f03404619970c4ba4bca2781a08a/` |
| `full.bin` sha256 | `9b6580f286741890af1eea1e9071c0f512a7f03404619970c4ba4bca2781a08a` |
| `app.bin` | **2,915,024** B（≈2.780 MiB；相对 P2 前 −11.9 KiB） |
| 校验 | `python3 tools/archive_firmware.py verify <归档>` → **PASS** |
| 选用原因 | P2：体积报告工具 + 关 Montserrat + 帮助文案抽出 |

### 预算

factory `0x7F0000`（8,323,072 B）；占用 **35.02%**；**空闲 5,408,048 B（65.0%）**。

### 主要消耗（对照 [`FLASH_SIZE_PLAN.zh_CN.md`](./FLASH_SIZE_PLAN.zh_CN.md)）

| 桶 | 字节 | 说明 |
| --- | --- | --- |
| 精灵 ASR1（36 帧 RLE） | 1,316,600 | `ashbox_flash_size_report.py` + encode `--check` |
| 电台 PCM×5 | 247,884 | 符号起止 |
| 暖炉 PCM | 384,000 | `hearth_fire.pcm` |
| PCM 合计 | 631,884 | 电台 + 暖炉 |
| 字形 bitmap（链入） | ≈106,480 | `ashbox_font_16`；Montserrat 符号 **0** |
| 空闲 | 65.0% | 非紧急 |

### 计划对照 / 可做与禁做

相对此前约 2.79 MiB app：P2 约减 12 KiB（关 Montserrat + 关 LVGL examples/demos）。精灵无漂移。空闲 **>40%** → 无需为体积砍内容。

**可做（无损）：** 继续 LVGL/printf 修剪；O-GAME1 settle/归来拆 TU。  
**禁止（除非当场改口）：** 砍景/砍帧、缩小 240×176、有损图、缩电台 PCM、为体积砍玩法档。
