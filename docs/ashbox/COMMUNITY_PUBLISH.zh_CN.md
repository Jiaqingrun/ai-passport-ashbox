## 导入 / RESTORED 说明（必写）

游戏说明须保留（或补回）下列玩家向表述：

1. 社区商店安装/更新会**清空整机**；更新前先用存档管家备份，装完再导入。
2. **本机**已有余烬进度，开机后会自动续上（含较早存档迁移）。这**救不了**未备份就装社区包的清空。
3. 设备上游戏存档在 NVS **命名空间** `ashbox`、键 `save`（blob magic `ASH2` **不是**命名空间名）。
4. 导入后以设备画面为准（天数 / 仓库 / 线索）。若网页显示「写入后读档失败」（`RESTORED 3`）：先看设备进度；若已是备份内容，升级《余烬》固件即可（旧固件可能把成功误报成 `3`）。若进度不对，再用 `Ember-before-import-…emsave` 导入，并保留原备份。
5. 仅限同一 `device_id`；确认覆盖时默认焦点仍在「取消」。
