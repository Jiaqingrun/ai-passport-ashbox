## 3. 设计原则（填充时不可破）

1. 循环仍是：出发 → 墙钟/深睡 → 归来抉择 → 危机/调查；不新开第二时钟。  
2. 七成放置经营 + 三成醒着废土剧；峰值放在归来抉择与守夜。  
3. 一切增长有盖；活跃是加成不是门槛。  
4. 社区文案不写芯片/框架；新中文必须进 `ashbox_font_symbols.txt` 并重生字体。  
5. 优先占用**已有死枝/扩表**，避免无接线的「幽灵文案」。  
6. 三键 UI：战报/列表仍 ≤3 抉择；途中句与电台单行可读（建议目标 ≤22 汉字可视，可滚）。

## 4. Phase F · 内容填充优化方案

**玩家一句话：** 每条路回来都不像同一趟；匣里低语终于听得见；过夜与猎场有自己的气味；守夜像真的怕了一晚。

### F0 · 接线急救（必须先做）

| 动作 | 做法 |
| --- | --- |
| 打开余烬低语步 0 | 将枝 4 或 19 挂入至少一处：标签「余烬发热」池；和/或深处成功 outcome；和/或教程后近路成功池一侧 |
| 可选 catch-up | 仿 `sync_quest2_catchup`：首次深处成功且步 0 时自动推到步 1，并写纪事「匣里低语被听清了」——双保险 |
| 复活 20/21 | 废街失败或信任冲突标签中放入「道歉收场 / 翻脸走人」，或新建标签「站内口角」 |
| 灰潮 27/28 | 保持交易/收获系统推进；UI 线索页注明「换种/收获即推进」，避免玩家死等抉择枝 |
| 宿主单测 | 断言：新档可经「可到达路径」在 N 次归来内把 quest1 步 0→1；死枝扫描脚本进 CI |

验收：无干肉/无灰片路径下灰潮仍通；**余烬低语不再永久停在「听匣里低语」**。

### F1 · 分档 Outcome / 标签身份（核心体感）

| 档 | 内容策略 |
| --- | --- |
| 近路 | 保留教程+邻里社交；加 2–3 条「货亭气味」枝 |
| 废街 | 独立成功/失败池（可从现池拆 + 新枝）；偏脚印、空货架、螺丝 |
| 深处 | 保持灰片/铁棚/余烬向；确保步 0/1 枝可见 |
| 猎场 | **新建** outcome 或强制标签「干肉香 / 反潮夜」池：分享热汤、囤干肉、戒备、埋痕迹；禁止再默认近路社交三选一 |
| 过夜 | **新建** outcome：长夜疲惫、门后风、外环潮声；失败偏休养/压话/戒备；战报行模板写「走了一整夜」而非深处复读 |

技术：扩展 `k_outcome`（建议 +4：猎成/猎败/夜成/夜败），改 `pick_outcome_id`；标签表 +2～3（猎径、长夜、口角）。存档：纯内容表，**可不升 VER**。

### F2 · 战报与危机峰值文案

1. **战报行模板库**（按档×成败×人物抽 1 句环境 + 1 句掉落）：例如过夜成功 L0「阿禾在外环喘匀了」、L2「潮声一整夜没断」。仍限 32 字节，短句优先。  
2. **危机选项旁白**：每选项 1 行副标题（交涉「阿禾先开口」/ 加固「耗件保闸」/ 躲藏「小芒捂住呼吸」）；了结 journal 分三种语气，不再共用一句。  
3. **分支 log** 把会计账感让给 effect 行；log 写场面（已有多数枝），补齐猎/夜新枝。

### F3 · 途中与电台厚度

| 层 | 目标量 | 规则 |
| --- | --- | --- |
| `k_away` | 25 → ≥40 | 按档分段：近路 0–9、废街 10–19、深/猎/夜 20–39；长档禁止只啃末 4 句 |
| idle | 13 → ≥20 | 中后期变体：仓满后、开闸后、猎装后各 2 句 |
| lore | 8 → 12 | 同档 2 变体，用 `day_key` 抖选，避免灰片=3 永远同一句 |
| twist | 3 → 8 | 了结后分「退潮 / 旧城自熄 / 渡口记忆」三主题 |

电台硬钩（断粮/仓满/可收）保留优先级；氛围句不得盖过硬钩。

### F4 · 站事 / 日勤 / 帮助教程式

- 站事：4 种保留，但 **label/hint 按 `exp.tier` 换皮**（过夜「听外环潮」、猎场「晾干肉绳」），奖励表可不变。  
- 日勤：增加 2 句轮换纪事文案（听广播已有落纪事逻辑则加厚句子）。  
- 帮助：8 行改为「操作 4 + 进度 4」：开闸要烬、猎场要闸、灰潮换种或灰片、过夜适合睡眠；调查线点名三线标题。

### F5 · 角色气味（不加系统）

- 归来 L0 已有「X回来了」；按 pid 加可选第二句气质（阿禾稳、老阙修、小芒线索）——仍 ≤32 字。  
- 标签偏置已照顾小芒；补 1 条老阙向标签「轴承盒」挂修理枝。  
- **不做**第四人、不做好感度数数值（信任已够）。

### F6 · 明确不做

- 新货币、第四营地、扩大菜地畦数、强制日勤才产。  
- 清档转生、付费加速、Wi-Fi 排行。  
- 把「余烬低语」改成自动全文跳过（允许步 0 catch-up，不允许无文本瞬结）。  
- 为填文案而放大 Flash/字库到不可控；新字批量进子集表后跑字形门禁。

## 6. 文案语气宪章（填写时用）

- 短、可念、少形容词堆叠；多用「铁皮 / 灰 / 匣 / 灶 / 闸」。  
- 威胁用脚步、潮声、空罐，不写血腥细描。  
- 调查线收束要有一句「了结后世界多了什么」（已有渡口/掉落加成），电台 echo 一句即可。  
- 同义不换概念：稻谷种≠谷；红薯种≠薯；干肉≠肉（战报可缩写但帮助用全称）。
