# 《余烬》正式向延伸设计

测试版终点 = 正式内容起点。本页约束**怎么长**，避免资源爆炸、存档撑破、三键 UI 过载。

## 设计原则

1. **仍以现有循环为核**：出发 → 墙钟/深睡 → 归来抉择 → 危机/调查；新系统挂在 `ash_game_settle` 与管理页，不另开第二套时钟。
2. **玩法优先文案**：不写芯片/框架；社区简介只谈「门后、营地、种地、仓库、交易、猎场」。
3. **一切增长有盖**：口粮/零件/仓库/物品均有硬顶；加减用饱和运算；生产在顶满后停止，不回绕。
4. **分阶段解锁**：闸门 → 猎场；食堂 Lv2 → 菜地；深处通联 → 铁棚营地交易；灰潮了结 / 猎场偶遇 → 灰河渡口。
5. **存档只追加**：`ASHBOX_SAVE_VER=11`，新字段插在 `crc` 前；旧 ver 安全迁移。玩法收口可复用空闲字节（`pad_v10b` / `pad_v11`），布局允许时不强制升版本。

## 世界层（叙事）

| 元素 | 落地 |
| --- | --- |
| 门后的世界 | 闸门开启后电台/纪事解锁「门后」句；深处掉落「灰片」推进认知 |
| 灾难原因 | 不一次说完：灰片 0→4 逐步改写电台闲句（灰潮 / 旧城熄火 / 余烬来历） |
| 幸存者营地 | **铁棚营地**：深处成功后可通联；日限交易。**灰河渡口**：调查线了结或猎场偶遇通联；另计日限，换薯种 |

### 调查线「门后灰潮」（qid=2，进度在 v4 追加字段）

| 步 | 提示 | 推进 |
| --- | --- | --- |
| 0 | 开闸后听门外风声 | 开闸（打开站门，解锁猎场）/ 归来抉择「听门后风」；旧档已开闸则 settle 补齐 |
| 1 | 通联铁棚营地 | 深处通联 / 「回访铁棚」；已通联则 settle 补齐 |
| 2 | 用干肉换谷种 | 铁棚交易「干肉换谷种」成功 |
| 3 | 田地种活并收一次 | 菜地收获成功 |
| 4 | 拼齐灰片听潮因 | 抉择「拼起灰片」；深处成功且灰片≥2 亦可收束 |

了结奖励：信物+1、灰片认知拉满（电台闲句）、威胁-8（有底）、开通灰河渡口并赠薯种，有盖。

## 系统层

### 仓库

- 口袋口粮仍受食堂容量；零件顶 999。
- **仓库容量由 `stash_lv` 独立决定**（40/100/180），建设页零件扩容；可存入/取出（每次 5）。
- **仓家具 `furn_lv`**：Lv1 货架（+20 仓容）；Lv2 干燥架（耗 1 信物；settle 时生长约 ×8/7，中途安装也生效）。
- 产出优先填口袋，口袋满则溢入仓库，仓库满则停产；战报入账同样溢仓。口袋空且仓有粮时自动回补。电台钩子（断粮/仓满/可收）优先于纪事。

### 物品（固定 4 类 + 薯种分列，各有盖）

| ID | 名称 | 来源 | 用途 |
| --- | --- | --- | --- |
| 种 | 稻谷种 | 通联铁棚 / 交易 / 远征偶得 | 种稻谷 |
| 薯种 | 红薯种（`seed_root`） | 渡口 / 猎场偶得 | 种红薯 |
| 干肉 | 干肉 | 猎场成功 | 仓库「干肉换口粮」（+4，有盖/溢仓）；或铁棚/渡口交易 |
| 信物 | 铁棚信物 | 交易结余 | 干燥架等 |
| 灰片 | 灰片 | 深处偶得 | 叙事/电台 |

### 菜地（2 块田地 · 双作物）

- 解锁：食堂 ≥ Lv2。玩家文案统一称「田地」，不再用「畦」。
- **稻谷**：耗 1 稻谷种；约 4 小时墙钟；收获 +4..6。
- **红薯**（需渡口）：耗 1 红薯种；约 6 小时；收获 +7..10；干燥架在推演中催熟（约 ×8/7）。
- **远征档**：近路 / 废街 / 深处 / 猎场 / **过夜（约 8 小时，适合睡眠挂机）**。
- 推演：稳住但不飞升；顶满停产。

### 交易

- **铁棚**：通联后；`trade_day` 日限一次：粮↔件、干肉→谷种。
- **灰河渡口**：通联后；`trade2_day` 另计日限：干肉→薯种、件5→薯种。
- 全部经容量截断；不能刷出超额。

### 猎场（第四档远征）

- 解锁：闸门已开。
- 约 2 小时；成功：口粮 + 干肉（有顶）；失败：受伤 + 威胁有限上升。
- 铁棚已通联时偶遇可开通渡口；亦可能掉薯种。

**Phase C 玩家可读意义（一句话）：** 铁棚管「件/谷种」；渡口管「更饱但更慢的薯」；货架防仓满停产，干燥架催熟菜地——中期用吞吐稳住三人站，而不是再堆平行系统。

## 双角色讨论与宿主推演（Phase D 依据）

宿主脚本 `tools/sim_ashbox_roles.c`（不进固件）用现有 `ash_game_*` 各推约 96 墙钟小时。两名角色共用三键闭环，只换优先级。

### 角色甲 ·「匣主」——调查优先

- **打法：** 近路热身 → 尽早深处 → 开闸 → 继续地铁刷灰片/余烬；食堂先升到菜地。
- **模拟实录：** ~4h 深处通联铁棚并得谷种；~12h 攒满 3 烬开闸；灰片可到 4；96h 末口袋+仓满、零件 300+、余烬堆到 11。
- **甲的抱怨：** 「开闸之后余烬没地方花；灰潮卡在『用干肉换谷种』——通联白送的谷种能种，但调查步仍要干肉，我不打猎就永久卡步；电台只喊仓满。」
- **甲想要的下一层：** 余烬养成/装备槽、灰潮绕过干肉的等价路径、灾因文案在灰片满后继续反转。

### 角色乙 ·「猎径」——吞吐优先

- **打法：** 近路 → 废街刷件粮 → 等烬开闸再进猎场换干肉/渡口。
- **模拟实录：** 96h 内废街约四十趟，**余烬仍为 0**（废街掉烬约 2%，期望不足 1）；闸门未开 → 猎场/干肉/渡口全锁；零件近 500、仓满；灰潮停在通联前/交易步。
- **乙的抱怨：** 「不跑深处就几乎摸不到烬，猎场流派开局是沙漠；仓满后零件通胀没有体面消耗；站事有趣但喂不进中期目标。」
- **乙想要的下一层：** 非深处也有稳定烬来源（软保底）、猎装让废街/猎场有成长感、营地声望把日限交易变成中循环。

### 共识（两人拍板）

1. **开闸是第一道沙漠：** 深处保底 +1 烬，近路/废街 1%–2%。只跑吞吐的人可能数天不开闸——违背「放置必须能挂着前进」。
2. **灰潮步 2 是软锁：** `sync_quest2_catchup` 在通联后推到「换谷种」，但免费谷种不推进；无干肉则收获也不认步 3。
3. **中期通胀：** 仓满后零件与余烬缺乏自愿有回报的沉淀；扩建盖在 Lv3 后飞轮空转。
4. **不要第二套时钟、不要清档转生、不要付费加速**——硬件是离线三键玩具，合规与体验都要求「回来就有进展，不回来也不受罚」。

### 放置设计外参（合规滤镜）

参考 Incremental Design Codex / GameDesign.gg《Design of Waiting》、独立放置数值飞轮与离线上限实践，**只吸收护肝原则**：

| 吸收 | 不吸收 |
| --- | --- |
| 短/中/长三层循环同时在场；避免 unlock desert | 清档 prestige / 战力赛季重置 |
| 活跃是加成不是门槛；离线有盖有衰减（已有深睡折算） | 强制每日登录、断签惩罚 |
| 产出 ≈ 消耗 + 自愿沉淀；软盖溢出转向别加成 | 硬墙战力、抽卡、概率付费 |
| 新层改优化问题，不只加倍数 | 平行孤岛系统、社交压力 |

## Phase D · 可行升级计划（合规优先）

**玩家一句话：** 余烬终于能武装猎径；铁棚与渡口记得你的脸；灰潮真相会翻一次——全程无付费、无清档、无第二套时钟。

### 合规硬轨（任何切片不得违反）

1. 无内购、无广告、无抽卡、无「加速券」；社区文案不写芯片/框架。
2. 存档只追加（现行 `ASHBOX_SAVE_VER=11`）；旧档可玩、不因未做 D/G 而残缺。
3. 一切增长有盖；加减饱和；生产顶满停，不回绕。
4. 离线/深睡继续按现有折算；禁止「必须在线才能涨」的新资源。
5. 活跃奖励（站事、装载、声望日限）只能是**可选加成**，不能变成唯一通道。
6. 叙事反转不抹掉已了结调查线；只追加电台/纪事层。

### 切片顺序（每片可单独合入 + 宿主单测）

| 序 | 切片 | 玩家感知 | 技术要点 | 盖 / 门 |
| --- | --- | --- | --- | --- |
| **D0** ✓ | 沙漠与软锁急救 | 废街也能慢慢见烬；灰潮不必卡死在干肉 | 近路/废街/猎场软保底（12/10/8）；灰潮步 2：干肉换种 **或** 交 2 灰片；收获可补推进步 2 | 烬有盖；深处曲线不变 |
| **D1** ✓ | 余烬沉淀 · 猎装 | 开闸后烬有去处；猎场/废街略稳 | `gear_lv` 0..2：耗烬 3/5 + 件 4/8；猎失败率↓、干肉+1、挂彩威胁↓ | 失败率地板≥5% |
| **D2** ✓ | 营地声望 | 日限交易变成中循环 | `rep_shed` / `rep_ferry` 0..3；成功交易 +1；声望≥2 解锁同日第二次换 | 声望有盖；仍 clamp |
| **D3** ✓ | 零件自愿沉淀 | 仓满后零件能换「站内安心」 | 建设「静音轮」18 件；威胁上涨分子 -2（底 5） | 不删站令 |
| **G0** ✓ | 后期零件沉淀 II | 静音轮后零件仍有体面去处 | 建设「门扣」24 件（需静音轮）；威胁再 -1（底 4）；加固费用 -1（底 1）；存档 ver 8 | 一次性有盖 |
| **D4** ✓ | 灾因反转 | 灰片满/灰潮了结后电台换层 | `lore_twist` + 三句反转广播 | 纯叙事 |
| **D5** ✓ | 宿主推演门禁 | 防回归沙漠 | 单测：烬保底、灰片路径、猎装/声望/静音、废街开闸期望 | CI 宿主侧 |

### 明确不做（本阶段）

- 转生/清档倍数、第四营地、第三人称战斗、Wi-Fi 排行、儿童向付费点。
- 把深处重新锁进闸门（逻辑上深处已可走；UI 仅猎场未开闸——保持，避免再制造沙漠）。
- 扩大菜地畦数或取消日限交易（防通胀优先于「更大数字」）。

### 验收（D 合入前）

- `./tools/validate.sh --static`；相关宿主断言绿。
- 字库覆盖新中文（猎装/声望/反转句）。
- 社区更新说明只写玩家可感知句；配图不冒充实机截屏。
- **社区更新必写：** 官方安装会覆盖设备全部内容；不是本机保档刷机；重新安装会清空进度——勿承诺不丢档（见 [BUILD.zh_CN.md](./BUILD.zh_CN.md)）。
- 真机：开闸前废街见烬或保底；开闸后烬可升猎装；灰潮无干肉可走灰片等价步。

## Phase E · 现有环丰满（风格宪章落地）

双设计师辩证结论：**七成放置经营 + 三成醒着废土剧**；加深现有核，不开新地图。峰值在归来抉择/守夜；活跃是加成不是门槛。

| 序 | 切片 | 玩家感知 | 技术要点 | 盖 / 门 |
| --- | --- | --- | --- | --- |
| **E0** ✓ | 站内日勤 | 不想挂机也能点：听广播/看闸/清点/看灶 | 复用原 `reserved_v5`→`duty_day`/`duty_count`；每日≤3；据点首项；非远征 | 小奖励有盖；非门槛 |
| **E1** ✓ | 站事/人选加厚 | 站事纪事更具体；小芒更易出线索标签 | 分种 log；pid2 偏调查标签池 | 仍≤2 站事/征 |
| **E2** ✓ | 文案与帮助 | away/电台/帮助写清日勤 | 仅用现有字库字形 | — |

**明确不做（E）：** 第四营地、第二货币、必须日勤才产、扩大菜地畦数。
