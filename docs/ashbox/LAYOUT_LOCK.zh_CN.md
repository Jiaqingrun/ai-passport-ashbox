未经理明确新设计决策，禁止改动下列数值与家园壳结构。日常「再挤一点 / 再松一点」不在范围内。

## 家园 HUD 规则（已定死）

- 不显示「人x/y」；人数靠精灵景（`IDLE` / `DUO` / `AWAY` 等）表达。
- 远征 / 危机 / 战报只在「此刻」行表达，资源行状态不再重复。
- 电池为分段电芯匣（无百分比、无「烬」字标）。
- 主/次底键必须同一 `BTN_Y`，沿用双键几何。

## 权威位置

`main/ashbox_ui.c` 中 `STAGE_H` / `SAFE_TOP` 一带 `#define`。精灵尺寸：`tools/ashbox_sprites_encode.py`（`W, H = 240, 176`）与 `assets/ashbox/sprites/`。
