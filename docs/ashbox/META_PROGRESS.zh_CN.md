## 通关事件（唯一）

**通关** = 三条调查线全部 `quest_done` 且 `lore_twist == 1`（与电台「了结」一致）。  
立一次 `run_cleared`；可继续玩。结算可一次解锁多枚成就。

## 人口与床位

- `ASHBOX_PERSON_MAX = 6`
- 宿舍床位：L1=2、L2=3、L3=4、L4=5、L5=6（L5 需超级核心抬建筑顶）
- 人口上限仍 = `min(床位, 食堂/工坊劳动力档)`

## 派工（在站）

| 职务 | 效果 |
| --- | --- |
| 休整（默认） | 回疲劳 |
| 田作 | 催熟菜地 |
| 工坊 | 加快零件产出权重 |

外出锁定「在外」。虚弱可派工，效率减半。

## 疲劳

休整：基础 −12/时，宿舍每高一级 +2，硬顶 −24/时。  
田作/工坊：回复减半或不回。禁止无条件 −24 再叠全速干活回复。

## 无人 / 强制终局（MVP）

1. `pop==0`：站内口粮/水/威胁消耗为 0；产水与菜地继续；零件产出为 0。
2. 过路客仍按原计时；接收代价不变。
3. 强制失败：`pop==0` 且连续两次付不起/打发（`wipeout_reject_count >= 2`）。

## 成就（元进度位图）

| 位 | 名 | 解锁 | 新开局发放 |
| --- | --- | --- | --- |
| 0 | 孤勇者 | 通关时 `pop==1` | 手枪×1 |
| 1 | 结伴而行 | 通关时 `pop` 为 2 或 3 | 背包×2 |
| 2 | 人多势众 | 通关时 `pop>=5` | 手枪×2 + 子弹×10 |
| 3 | 和平主义者 | 通关前从未装备/携带手枪与子弹 | 仓库口粮容量 +50 |
| 4 | 无人生还 | 通关时 `pop==0`，或通关后强制终局仍空且未再收人 | 超级核心×1（生涯一次） |

本局解锁 → 弹「重新开始后生效」；**当前局不发奖**。  
设置 → 重新开始：清 `save`、留 `meta`、发永久开局物；超级核心仅在已解锁且未消耗时进库存一次。

## 超级核心（本局道具）

生涯使用一次（`meta.super_core_consumed`）：

- 田地 2 → 4
- 建筑等级顶 3 → 5（`build_cap_bonus=2`）
- 成功远征口粮/零件/铁 ×1.5（`loot_bonus_perm_pct=50`）；空手而归概率不乘

## 枢纽 / 设置

- 据点 **幸存者**：列表姓名+状态+疲劳；详情信任/个性/伤病/职务/装备
- 据点 **成就**：未获灰、已获金；条件与加成用大白话
- 设置 **重新开始**：取消键默认（与导入同风险级）
