# 余烬（Ember）

三键掌机上的离线末世据点模拟。你守着一间暖炉小屋和几个幸存者：派人按时间
出门搜刮，分配口粮与水，建设、交易，压住每晚上涨的威胁，还得顺着三条调查线
把故事翻下一层。不联网、不登录，熄屏之后世界仍在走。

**作品描述（发布原文）：**

把 AI Passport 变成你口袋里的离线末世据点《余烬》。

家园正中是一间暖炉小屋：有人在，炉火就旺；有人出门、菜地该收、仓满了、能交易、门口不对劲、有人归来、夜里醒来，屋子就会换成那一幕。主页还能长按上下键，在「当前局势下能看的站台景」之间切换——危机、战报这类要紧时刻只会锁住那一景，不会随便乱切。炉边偶尔响起木柴噼啪。你管口粮、水、铁、零件和余烬，派阿禾、老阙、小芒去废墟搜刮。可以醒着把据点收拾好，也可以盖上深睡，把时间交给废土，醒来再听他们带回什么。

出门先选路、再选人，还能带上撬棍或手枪和子弹。近路最稳（基础空手而归概率约5%），废街刷口粮和零件（约12%），深处专冲余烬与灰片（约18%，余烬概率约35%），开闸后能去猎场拿干肉（约20%），过夜适合盖上睡一觉（约22%，余烬概率约45%）。信任、疲劳、猎装、手枪还会改这些概率；开闸后多数路掉落约多两成，猎场除外。成功回来但没捡到零件时，战报会写明并常多给一点水。

人在外面时，空闲只会把画面调暗，不会自动黑掉：远征倒计时还在走。要省电可以长按确定深睡；醒来会按实际过掉的时间把进度补上。整机关机时倒计时会停住；只有深睡醒来才会补上。人回来选分支、以及守夜危机，必须醒着处理。

据点里能建设、交易、种菜、扩仓、看线索、设过夜站令、做日勤。建设页先支工作台，再在装备页做水罐、撬棍、手枪和子弹。零件用来盖屋子、扩仓库、装静音轮和门扣；铁用来做随身装备。仓位按大白话算：大约口粮300占一仓、铁50占一仓。旺仔牛奶清疲劳；重伤大约一天内要用肾上腺素，拖过就撑不住；抗生素退热伤。过路客要留下时，会先弹出本事与加成再确认。威胁顶到大约80会逼你守夜。三条调查线推完还能继续过日子。

## 它做了什么

- **五种资源的循环**：口粮、水、零件、铁、余烬，各有口袋、仓库与上限。余烬既是
  货币也是后期资源。顶栏常驻五格资源条，主页画面下方另有一条五格条。
- **把概率写在明面上**：五档路线——近路（约 3 分钟）、废街（1 小时）、深处
  （4 小时）、猎场（2 小时，需先花 3 余烬开闸）、过夜（8 小时）。每档副行都写清
  粮水消耗、掉落区间、基础空手率与余烬概率；信任、疲劳、携带装备与开闸加成都会
  改这些数字，带手枪还能挡下一次突然袭击。
- **是人不是数值**：三个幸存者各有偏向（稳、偏零件、偏线索），各有信任与疲劳。
  信任降低空手率，疲劳过高会降低产出并禁止出门。伤病分两种：约一天内不注射
  肾上腺素就会倒下的重伤，以及约 36 小时才退成虚弱的发烧。
- **威胁与守夜**：威胁随时间上涨。到 80 且无人外出时必须醒着处理：交涉、加固或
  躲藏；到 100 门被顶开，威胁回落到 79，接下来六小时安静，但要赔上零件。危机页
  是真正的决策点而不是摘要——可以放着让设备睡，它不会自己消失。
- **有取舍的建设**：宿舍、食堂、工坊、闸门、仓储扩容、仓家具、水井以及一批小件。
  每一级都更贵，且都带一项代价——工坊加快零件但更吵、食堂省口粮、水井升级只暂停
  井水、宿舍升级歇得快但不多吃粮。
- **三条调查线与元故事**：铁皮来客、余烬低语、门后灰潮，各五步，每天只能往前走
  一步（花 8 个零件当天可再走一步）。三线走完且故事翻层算通关；之后还有两段新程，
  威胁地板更高、掉落更少。
- **深睡与真实时间补账**：游戏走真实时间。深睡时远征、田地、水井按完整墙钟推进，
  而耗粮、零件产出、威胁上涨与用水按打折系数计；醒来给一份说明。站内熄屏不会
  把还在跑的远征倒计时藏起来。
- **纪事、电台与过夜站令**：短日志的环形缓冲、有人在外时会切换到「在外」台词的
  电台，以及只影响深睡段的过夜站令（不设／节食／戒备／赶工）。

## 操作

- **短按上／下**：移动高亮、在主页按钮间切换、翻列表。
- **短按确定**：进入、确认、翻开局说明、推进战报。
- **长按确定**：从任意内页返回上一层；在主页请求深睡（松手生效，再按取消）。
- **长按上／下**：主页上切换与当前局势相符的站台景；帮助页里在八个分节间跳转。
- 顶栏常驻待办角标（战报／危机／站事／过客／可收／仓满／可换），「此刻」只说当前
  最要紧的一件事。
- 需要阅读的提示会占住屏幕等你按确定，不会被下层页面的重绘抹掉。

## 存档与安装

- 存档在 NVS 的 `ashbox` 命名空间、`save` 键，magic `ASH2`，ABI 版本 13、776 字节，
  旧档在读档时迁移；跨局元进度用 `meta` 键与 `ASHM` magic。
- 设置里的备份／导入实现 `!EMBACKUP` USB 协议，配合
  [存档管家](https://github.com/Jiaqingrun/AI-Passport_BS) 的 `save-manager-v1.0.1`：
  备份会校验后写成 `.emsave`；导入会先把当前进度存成 `Ember-before-import-…`
  再请求确认。
- 社区商店的安装或更新写的是整片镜像并会清空设备（含本存档）。要留进度请先备份，
  装完再导入；只刷应用区（偏移 `0x10000`）则保留 NVS 与存档。

## 源码与代码结构

- 应用代码在 <https://github.com/Jiaqingrun/ai-passport-ashbox> 的
  `feature/ashbox-ember` 分支，不在上游。
- `main/ashbox_game.c` 是规则核心（有主机测试），`main/ashbox_content.c` 是内容表，
  `main/ashbox_ui*.c` 是 LVGL 应用外壳（主页、内页、交易、战报），规则调用都放在
  应用运行时锁内；`main/ashbox_save.*` 实现 NVS 存档、迁移与双槽 CRC，
  `main/ashbox_backup.c` 实现 USB 存档协议。
- UI 是为本应用专门写的壳，不是硬件测试菜单。中文界面使用 16 px 子集字体，由
  `main/ashbox_font_symbols.txt` 重新生成。
